Assignment 4 - Components
===
## Reading Tracker

https://a4-angela-long.onrender.com

For Assignment 4, I updated my Assignment 3 Reading Tracker to use React components. The Reading Tracker allows users to add books, track their reading progress, edit book information, and delete books from their reading list. For this assignment, I used React to display and update the reading list while keeping the login functionality from Assignment 3.

Using React improved the development experience because it made it easier to organize and update the reading list. Using components helped separate different parts of the application, and React state made it easier to update the books being displayed. It took some time to change my Assignment 3 code to work with React, especially when connecting my existing form to the React components. Overall, I think React made the code easier to organize once I understood how everything worked together.
